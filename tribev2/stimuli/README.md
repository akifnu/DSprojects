# Stimuli

Sample inputs for TRIBE v2 capability tests.

| File | Modality | Purpose |
|------|----------|---------|
| `language_content.txt` | Text | Language-network contrast (condition A) |
| `visual_spatial_content.txt` | Text | Visual/spatial contrast (condition B) |

## Optional media

Add your own files to enable audio/video benchmarks in `config/default.yaml`:

- `sample_audio.wav` — speech or natural sound (`.wav`, `.mp3`, `.flac`, `.ogg`)
- `sample_video.mp4` — short naturalistic clip (`.mp4`, `.avi`, `.mkv`, `.mov`, `.webm`)

Short clips (10–30 seconds) keep first-run encoder downloads manageable.
